# 最终 HTML 实验汇总的数据分析与后续科研路线

> 分析对象：`all_experiments_dashboard.html` 及其同源数据 `all_experiments_dashboard_data.json`。以下结论只针对当前看板中已标注为正式实验、且指标口径可核对的结果；Smoke、无法验证和缺少统一字段的记录不作为证据。

## 1. 先给结论

当前结果已经形成了一个**有研究价值、但尚未达到“方法有效性已被充分证明”**的实验信号：

1. **Adapter + Continual 在 CSI300 上改善了横截面排序和逐样本方向判断，但没有证明点预测误差或可交易 alpha 稳定改善。**
   - Path RankIC = 0.0587，Endpoint RankIC = 0.0612。
   - Path 方向准确率 = 53.32%，Endpoint 方向准确率 = 53.99%。
   - 但正式 Kronos AER 为 Path = -0.1309、Endpoint = -0.0049，说明经过 TopkDropout、持有期、交易时点、成本和基准处理后，当前收益优势不稳健。

2. **“点预测更准”与“排序更有用”并不一致。**
   - ABCD-C 的 CSI300 点预测 MAE 最低（0.05448），但 RankIC 几乎为零，组合 Sharpe 为负。
   - Adapter + Continual 的点预测 MAE 略差（0.05531），但 RankIC、方向准确率和 Q5-Q1 更好。
   - 因此后续论文不应把 MAE/RMSE 作为唯一主目标，应明确把横截面排序、方向和成本后组合表现作为主评价对象。

3. **持续学习确实值得继续研究，但当前证据不能把提升单独归因于“continual”。**
   - Continual-C 的 CSI300 Path RankIC = 0.0724，高于 Adapter + Continual 的 0.0587；Endpoint RankIC = 0.0624，与 Adapter + Continual 的 0.0612 接近。
   - Adapter + Continual 方向准确率更高（Path 53.32%、Endpoint 53.99%），但其组合 AER 并未同步转正。
   - 这说明“适配器、排名损失、回放、更新门控”可能共同影响结果，必须通过同数据、同随机种子、同评估器的消融实验拆分贡献。

4. **目前最合理的科研定位是：**
   > 在严格 test-then-train 边界下，冻结时序大模型表征，通过轻量 Adapter、排序目标和历史回放进行在线/持续适配；方法对横截面排序与方向预测有初步改善，但收益稳定性仍需多窗口、多种子和成本敏感性验证。

这比直接声称“模型带来稳定超额收益”更符合当前证据。

## 2. CSI300 正式实验的核心对比

### 2.1 点预测：Adapter + Continual 不是最优，但已经接近可比模型

| 方法 | MAE | MASE | OOS R² | 解释 |
|---|---:|---:|---:|---|
| ABCD-A Zero-shot | 0.07084 | 1.3567 | -0.9647 | 点预测较差，但终点排序较强 |
| ABCD-B Linear head | 0.05524 | 1.0579 | -0.0917 | 点误差较低，但排序整体为负 |
| ABCD-C Adapter prediction | **0.05448** | **1.0434** | -0.0554 | 点预测最佳，但排序/组合弱 |
| ABCD-D Adapter ranking | 0.05585 | 1.0696 | -0.0833 | 点误差略差，终点排序优于 B/C |
| Adapter + Continual | 0.05531 | 1.0593 | **-0.0719** | 点预测中等，排序和方向更好 |

这里的点指标均为收益空间的 10-step trajectory pooled 口径。历史模型中存在以价格空间计算的记录，不能直接与上述收益空间 MAE 比较；后续应全部重算成统一的收益标签口径。

**研究含义：**

- 预测数值的均方误差下降，不会自动带来横截面投资价值。
- 排序损失可能牺牲少量点预测精度，却保留更有用的相对顺序信息。
- 后续应将“点预测任务”和“横截面排序任务”拆成两个明确的研究问题，而不是用一个 MAE 指标概括全部性能。

### 2.2 横截面排序：Adapter + Continual 处于较强但不显著的区间

| 方法 | Path RankIC | Endpoint RankIC | Path 方向准确率 | Endpoint 方向准确率 |
|---|---:|---:|---:|---:|
| ABCD-A Zero-shot | 0.0343 | **0.1190** | 50.20% | 未提供 |
| ABCD-B Linear head | -0.0618 | -0.0686 | 47.82% | 未提供 |
| ABCD-C Adapter prediction | 0.0060 | 0.0127 | 49.85% | 未提供 |
| ABCD-D Adapter ranking | 0.0281 | 0.0365 | 49.80% | 未提供 |
| Continual-A | 0.0343 | 0.1190 | 50.17% | 53.13% |
| Continual-B | 0.0058 | -0.0091 | 49.62% | 48.87% |
| Continual-C | **0.0724** | **0.0624** | 52.61% | 51.87% |
| Adapter + Continual | 0.0587 | 0.0612 | **53.32%** | **53.99%** |

需要特别注意：ABCD-A 的 Endpoint RankIC = 0.1190 很高，但它与 Adapter + Continual 不是同一种训练过程，不能据此简单断言持续学习“击败”零样本模型。更合理的解释是：零样本模型在终点排序上存在较强的单窗口表现，而持续适配模型在 Path/Endpoint 两个口径之间更均衡。

### 2.3 组合表现：毛收益有改善，成本后和 AER 仍不稳

Adapter + Continual 的组合汇总如下：

| 指标 | Path | Endpoint |
|---|---:|---:|
| Q5-Q1 | 1.1102% | **1.8320%** |
| Top10% 净收益 | 0.1594% | 0.2362% |
| Long-Short 净收益 | 1.4496% | **2.7997%** |
| Top10% 净 Sharpe | 0.3006 | 0.2951 |
| Top10% 净最大回撤 | -24.59% | -38.43% |
| 平均换手率 | 62.0% | 59.8% |
| Kronos AER | -0.1309 | -0.0049 |

当前最关键的矛盾是：

- 横截面 Q5-Q1 和 Long-Short 指标为正；
- 但 Top10% 净 Sharpe 只有约 0.30；
- AER Path 为负，Endpoint 接近 0；
- Endpoint 最大回撤达到约 -38%。

因此，当前结果更像是“存在一定排序信息”，而不是“已经形成可靠交易策略”。下一步的重点应从继续调模型，转向**确认信号是否跨时期、跨种子、跨成本和跨组合构造稳定存在**。

## 3. 统计证据强弱：目前只能作为探索性结果

Adapter + Continual 的横截面统计量：

| 口径 | IC 均值 | RankIC 均值 | RankIC NW t | RankIC block bootstrap 95% CI |
|---|---:|---:|---:|---|
| Path | 0.0782 | 0.0587 | 0.9456 | [-0.0585, 0.1978] |
| Endpoint | 0.0846 | 0.0612 | 0.9660 | [-0.0640, 0.2040] |

两种口径的置信区间都包含 0，NW t 值也低于常用的 1.96 阈值。对于只有 50 个测试日、且仅发生 2 次被接受模型更新的实验，这种统计不稳定是预期现象。

**因此论文中应使用以下措辞：**

- 可以说：当前窗口上观察到正的平均 RankIC、方向准确率超过 50%，并且排序信号具有初步经济意义。
- 不宜说：方法已经显著优于所有基线，或已经证明能稳定产生超额收益。
- 必须补做：多随机种子、多个滚动测试窗口、按日期的配对检验、移动块 bootstrap 和多重比较控制。

## 4. 目前结果暴露出的科研问题

### 问题 A：模型优化目标与最终评价目标存在错位

ABCD-C 的点预测最好，却没有形成好的排序；Adapter + Continual 点预测不是最好，但排序和方向较好。这说明当前训练目标可能把“数值拟合”和“相对排序”混在一起，导致模型在不同目标之间折中。

**研究问题：** 如何设计联合损失，使收益幅度预测、横截面排序和方向分类互相促进，而不是互相干扰？

### 问题 B：持续更新的有效性没有被严格隔离

Adapter + Continual 同时包含：

- Frozen hidden representation；
- trainable Adapter；
- 10-step prediction head；
- ranking loss；
- replay；
- validation RankIC gate；
- month-end update policy。

当前一次实验无法判断提升来自哪一个组件。

**研究问题：** 在严格时间边界下，哪一个组件真正贡献了跨时期适应能力？

### 问题 C：预测信号到交易收益之间存在较大损耗

RankIC 为正，但 AER 不明显，说明可能存在：

- 信号强度弱，无法覆盖交易成本；
- Top10 集中度和换手率过高；
- 预测日期到开盘成交之间有执行延迟；
- 组合持有与换仓规则削弱了短期信号；
- 基准、成本和风险控制改变了收益排序；
- 信号在部分日期有效、部分日期反向。

**研究问题：** 如何从“有预测信息”进一步得到“成本后可交易信息”？

### 问题 D：跨市场可迁移性还没有形成可靠结论

Yahoo S&P 500 上部分 Continual/Adapter 结果看起来较好，但其 AER 仍为负或接近 0，且 CSI300 与 S&P 500 的样本规模、交易日数量、市场结构并不完全一致。

**研究问题：** 适配器学习的是通用时序表征，还是只是在特定市场和窗口上重新拟合了局部模式？

## 5. 建议的后续科研路线

## 阶段一：先冻结评估协议，消除可比性问题

这是优先级最高的一步，建议先不继续调模型。

1. **统一标签：** 所有模型都输出并评估 `actual_return_1..10` 与 `pred_return_1..10`，点指标全部使用收益空间。
2. **统一排序口径：** 同时报告 Path 和 Endpoint 的 IC、RankIC、方向准确率、Q5-Q1、Top10、Long-Short。
3. **统一交易口径：** 固定成交价、延迟、持有期、换手定义、开平仓成本、最小费用、风险暴露和基准。
4. **统一样本边界：** 训练、验证、测试严格按日期切分；测试日标签成熟后才可进入下一次回放。
5. **统一输出 schema：** 每个正式实验至少包含：预测文件、逐日横截面指标、逐日组合收益、更新日志、配置、随机种子、数据 hash。
6. **把未提供字段保留为“无法验证”，不能用 0 代替。**

完成后，应把当前所有 CSI300 正式实验重新过一遍同一评估器，得到一张真正可比较的主表。

## 阶段二：做最小但完整的消融矩阵

建议先在 CSI300 上进行，固定测试窗口、固定数据划分和固定 5 个随机种子。

| 实验 | Adapter | Ranking loss | Continual replay/update | 目的 |
|---|---|---|---|---|
| S0 | 否 | 否 | 否 | frozen/zero-shot 基线 |
| S1 | 否 | 是 | 否 | 单独验证 ranking objective |
| S2 | 是 | 否 | 否 | 单独验证 Adapter |
| S3 | 是 | 是 | 否 | Adapter + ranking |
| S4 | 否 | 是 | 是 | 单独验证 continual |
| S5 | 是 | 是 | 是 | 完整 Adapter + Continual |

每个实验使用相同的 5 个 seed，例如 100–104；先以 5 个 seed 评估，若方向一致再扩展到 10 个 seed。

主结论不要只看单次最优值，应报告：

- mean ± std；
- 跨 seed 的胜率；
- 逐日配对差值；
- block bootstrap CI；
- 更新日前后性能变化；
- 成本后 AER 和最大回撤。

## 阶段三：把持续学习机制拆开研究

推荐的实验轴：

1. **更新频率：** 不更新、月末更新、双周更新、每周更新。
2. **更新门控：** 无 gate、validation RankIC gate、带容忍区间的 gate。
3. **回放策略：** 仅近期、近期/历史 70/30、时间均匀、按年份分层。
4. **回放容量：** 30k、60k、120k、240k。
5. **更新步数：** 1、2、5 epochs。
6. **目标权重：** `lambda_rank` = 0、0.1、0.2、0.5、1.0。
7. **可训练参数：** 只训练 head、head + Adapter、Adapter 的不同瓶颈维度。

这部分不建议一次做全因子网格。先做 2×2 的关键对照，再围绕最有影响的因素扩展，避免把测试窗口反复用于模型选择。

## 阶段四：建立真正的时间稳健性证据

当前只有 50 个测试日，不足以支撑强结论。建议建立多窗口 walk-forward：

- 训练窗口固定 90 日 lookback；
- 测试窗口按月或按季度滚动；
- 至少覆盖牛市、震荡和下跌阶段；
- 每个窗口都重新执行 test-then-train；
- 只在最终汇总时聚合窗口结果。

推荐主报告：

1. 每个窗口的 RankIC、Q5-Q1、AER；
2. 窗口胜率；
3. 最差窗口；
4. 交易成本敏感性；
5. 不同 top-k 和最小持有期下的稳定性。

## 阶段五：将“排序信息”转化为“可交易策略”

建议围绕以下方向继续：

1. **信号去噪：** 横截面 z-score、行业/市值中性化、winsorize、信号平滑。
2. **降低交易损耗：** Top10% 改为 Top20%、设置换仓缓冲区、提高最小持有期、只在信号变化超过阈值时交易。
3. **风险控制：** 行业暴露、风格暴露、单票权重、波动率缩放、组合 beta 中性。
4. **信号组合：** Path 与 Endpoint 加权，或用短/中期 horizon 的 rank ensemble。
5. **置信度筛选：** 只交易横截面分位差足够大、预测不确定性较低的日期。
6. **收益预测与排序分离：** 一个 head 负责 expected return，一个 head 负责 ranking score，再以稳定性或门控策略组合。

这里的研究目标不是把历史回测 Sharpe 调到最高，而是找到在不同成本、top-k、持有期和窗口下都不容易失效的规则。

## 6. 建议的论文主线与可检验假设

### 论文主线

**Frozen foundation representation + lightweight adapter + replay-based continual ranking for cross-sectional multi-horizon stock forecasting**。

### 可检验假设

- **H1：** 在严格无泄漏的时间切分下，Adapter + ranking loss 比仅训练线性 head 有更高的平均 RankIC。
- **H2：** 加入 continual replay 后，模型在后续市场阶段的 RankIC 衰减更慢。
- **H3：** Path 目标比 Endpoint 目标对短期噪声更稳健，或二者 ensemble 能提升跨窗口稳定性。
- **H4：** validation RankIC gate 能降低更新后的灾难性退化，但可能减少更新次数。
- **H5：** 交易成本和换手约束是从预测有效性到策略有效性的关键中介变量。

每个假设都必须对应预先定义的主指标和统计检验，不能看完测试集后再选择最有利口径。

## 7. 近期最值得执行的 4 个实验

按优先级排序：

### 实验 1：统一重评估所有 CSI300 正式预测文件

目的：解决不同实验的指标字段不完整、价格/收益尺度不统一、Endpoint 字段缺失问题。

输出：一张包含所有模型、所有日期、所有 horizon 的统一明细表。

### 实验 2：Adapter + Continual 多种子复现

建议 seed = 100, 101, 102, 103, 104。

固定当前配置，只改变 seed。重点观察：

- RankIC mean/std；
- 方向准确率；
- Q5-Q1；
- AER；
- 更新接受率；
- 更新后的性能变化。

### 实验 3：S0–S5 最小消融矩阵

在相同 seed 和相同 test window 上隔离 Adapter、ranking loss 和 continual replay 的贡献。该实验比继续调更多学习率更有科研价值。

### 实验 4：成本和组合构造敏感性

至少测试：

- 5/10/20/30 bps；
- Top5/Top10/Top20；
- 5/10/20 日持有；
- 有无换仓缓冲区；
- Path、Endpoint、二者 ensemble。

如果只有低成本、单一 top-k 和单一持有期下有效，应将结论限制为条件性有效。

## 8. 最终判断

当前看板已经支持一个清晰的研究方向：**研究大模型隐藏表征在金融横截面预测中的轻量持续适配，而不是继续单纯追求点预测 MAE。**

但当前证据还处于“发现现象”阶段：

- 方向和排序有正信号；
- 点预测没有明显优势；
- 交易成本后 AER 尚未稳定为正；
- 50 个测试日和单 seed 不能支撑强泛化结论；
- 组件贡献尚未通过严格消融拆分。

因此下一阶段最重要的不是再做一个更复杂的模型，而是：

> **统一评估器 → 多种子复现 → 组件消融 → 多窗口验证 → 成本敏感性 → 再决定论文结论。**

如果这些实验仍能保持正的平均 RankIC、稳定的窗口胜率，并且 AER 在合理成本下转为稳定正值，那么就可以进一步发展为完整方法论文；如果 RankIC 保持正但 AER 不稳定，则论文应聚焦于“预测排序/表征适配”，不要把贡献表述为可直接交易的 alpha。
