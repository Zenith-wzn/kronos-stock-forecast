# Adapter + Continual 论文竞争力评估

日期：2026-09-14

## 结论

当前项目已经足以形成一个有研究价值的论文方向，但还不适合以“方法已被充分验证”或“产生稳定交易 Alpha”的强表述投稿。最稳妥的定位是：冻结金融时间序列基础模型表征，在严格 test-then-train 边界下使用轻量 Adapter、排序损失、历史回放和验证门控进行跨时期横截面适配。

当前竞争力判断：

- 研究想法：中等偏上；组件组合完整，问题重要，但算法原语本身的独创性有限。
- 实验信号：有正向现象，但稳定性和归因证据不足。
- 顶级通用 ML 会议：目前偏弱，不建议直接投稿。
- 应用型金融机器学习/时间序列 venue：补齐消融、多种子、多窗口和严格回测后可以尝试。

## 方法本身的审稿人判断

当前 Adapter + Continual 的实现是 512 维冻结 hidden 输入，64 维瓶颈 Adapter（LayerNorm、down projection、GELU、dropout、up projection），接 10 步预测头；训练目标为 Smooth-L1 加权 pairwise ranking loss（`lambda_rank=0.2`）。测试期按月末执行 test-then-train，回放容量 120k，近期/历史比例 70/30，并用验证集 RankIC gate 接受或拒绝候选版本。

这条方法线的优点是：时间边界、成熟标签、回放来源和版本切换都有审计代码；模型参数高效；排序目标与金融横截面评价目标一致；可以自然提出灾难性遗忘、更新门控和成本损耗等研究问题。

主要问题是：Adapter、ranking loss、replay、monthly update 和 validation gate 同时变化，当前结果无法证明增益来自 continual learning；相对于已有 parameter-efficient tuning、online learning、replay 和 learning-to-rank 工作，尚未形成一个足够清晰的新机制或理论解释。

## 当前证据能支持什么

### Adapter + Continual 的 50 日严格评估

来源：`train3/_adapter_continual_v4_metrics/adapter_metrics_full.json`、`adapter_metrics_summary.csv`。

- Path RankIC = 0.0587，Endpoint RankIC = 0.0612。
- Path/Endpoint 方向准确率 = 53.32%/53.99%。
- 轨迹 MASE = 1.0593，OOS R² = -0.0719；点预测不是优势。
- RankIC moving-block bootstrap 95% CI 分别为 [-0.0585, 0.1978] 和 [-0.0640, 0.2040]，均包含 0；Newey-West t 约 0.95/0.97。
- 11 次月末更新中接受 4 次，说明 gate 有实际筛选作用，但样本不足以估计长期更新稳定性。
- 10 bps 普通组合下 Top10 净 Sharpe 约 0.30，最大回撤约 -24.6%/-38.4%；正式 Kronos AER 在路线文档中为 Path -0.1309、Endpoint -0.0049。

因此可以说“观察到正的排序和方向信号”，不能说“显著优于所有基线”或“已经证明稳定可交易”。

### 226 日 CSI300 结果

来源：`train3/csi300_top10pct_20250701_20260605_seed100/page3_adapter_continual_top30_drop3/Adapter_continual/summary.json`。

重构的 Top30 日频组合报告累计净收益 39.8%、基准 18.9%、年化 45.3%、最大回撤 -13.2%，但平均 RankIC 仅 0.0130，且该报告使用 daily next-step return 重构，不等同于 50 日 v4 的 Path/Endpoint 口径或官方 Qlib-style AER。它只能作为补充现象，不能与其他模型直接拼成一张主表。

### 多种子结果的边界

来源：`train3/sorting_reward_v1/multi_seed_summary.csv`。

CSI300 的 S4（持续排序头，不是完整 Adapter + Continual）5 seeds 平均 RankIC 约 0.0189±0.0115、年化净收益约 13.9%±7.5%、Sharpe 约 0.96±0.44；S&P500 S4 平均 RankIC 约 -0.0101±0.0124。该结果说明跨市场稳定性尚未建立，也不能替代完整方法的多种子复现。

## 主要审稿风险

1. **贡献归因不成立**：没有在完全相同数据、窗口、种子和评估器下隔离 Adapter、ranking loss、replay、update frequency 和 gate。
2. **时间口径不一致**：50 日 v4（2026-05-27—2026-08-05）、226 日 CSI300 正式窗口（2025-07-01—2026-06-05）以及 sorting-reward 矩阵不能直接比较。
3. **基线竞争力不足**：现有统一基线中，CSI300 future-mean LSTM 的 Top10 超额收益 0.2428%、Sharpe 3.58，高于 Kronos zero-shot 的 0.0969%、3.19；完整 Adapter + Continual 尚未在同一口径证明超过它。
4. **统计证据弱**：当前单 seed 或短窗口结果的置信区间跨 0，不能支撑泛化或显著性结论。
5. **金融数据有效性**：当前成分股回溯存在 survivorship bias 和当前成分股前视偏差；这在论文中必须明确，最好改用 point-in-time constituents 或把结论限定为固定可评价面板。
6. **回测可比性**：普通组合、Top30 重构组合和 Kronos AER 使用不同成交、持有、成本和换手规则；若不统一，审稿人会认为存在 metric shopping。
7. **跨市场证据不完整**：CSI300/S&P500 的部分 Continual 与 AER/Endpoint 股票级明细仍是“无法验证”，不能用摘要或 Path 值替代。

## 论文主张矩阵

| 结果状态 | 允许的主张 | 不允许的主张 |
|---|---|---|
| 维持当前结果 | 在严格时间边界下观察到正的横截面排序信号；轻量适配具有可行性 | 稳定 Alpha、显著优于所有基线、持续学习单独带来增益 |
| 5 seeds + 消融后 RankIC 稳定为正 | Adapter/ranking/replay 组合改善横截面预测，且组件贡献可分解 | 跨市场普适、无条件可交易 |
| 多窗口 + 成本敏感性后仍为正 | 方法在多个市场阶段保持一定时间稳健性，成本是重要中介 | 未来收益保证、实盘可直接部署 |
| point-in-time 股票池 + 统一 AER 后仍优于基线 | 有条件的成本后组合优势 | 无偏历史投资结论（除非成分股和 corporate action 也被严格处理） |

## 最小补实验包（按接受率提升排序）

### P0：统一主评估器

固定同一 train/val/test、同一标签（Endpoint 10 日收益 + Path mean）、同一交易延迟、top-k/drop-n、持有期、成本和风险指标。所有模型必须输出股票级 predictions、逐日指标、组合曲线、更新日志和 hash。任何缺字段保留“无法验证”。

### P1：S0–S5 消融 × 5 seeds

建议至少包括：frozen zero-shot、ranking-only、Adapter-only、Adapter+ranking、continual-only、Adapter+ranking+continual。主表报告 mean±std、seed 胜率、逐日配对差值、block bootstrap CI、更新前后性能。

### P2：多窗口 walk-forward

至少 3 个测试阶段，覆盖上涨、震荡和下跌；每个窗口重新执行 test-then-train。汇报窗口 RankIC、Q5-Q1、AER、最差窗口和窗口胜率，而不是只汇总所有日期。

### P3：成本与组合敏感性

成本至少 5/10/15/30 bps，top-k 至少 5/10/20%，持有期至少 5/10/20 日，并加入换仓缓冲区。若只有单一参数有效，论文结论必须降级为条件性有效。

### P4：数据与强基线

加入 point-in-time 成分股、复权/ corporate-action 审计，并与 LSTM、LightGBM/XGBoost、线性头、全量 fine-tune/LoRA、简单 EWMA/动量和现有 Kronos zero-shot 在同一评估器下比较。

## 投稿策略

现在更适合先写成“方法与审计协议 + 探索性结果”的工作论文或 workshop 草稿，不适合直接包装成稳定交易策略论文。若完成 P0–P3 且完整方法在多个 seed/窗口上持续击败强基线，才具备应用型金融 ML/时间序列会议的实质竞争力；若同时完成 point-in-time 数据和统一成本后 AER，才可以考虑更强的应用 venue。顶级通用 ML venue 还需要更明确的新算法机制、理论/机制分析或更广泛的跨市场证据。

## 当前建议的论文标题方向

不要使用“Stable Alpha”或“Superior Stock Returns”。更安全的方向是：

> Continual Cross-Sectional Adaptation of Frozen Financial Foundation Models with Lightweight Adapters and Replay

副标题或摘要中明确“prediction/ranking study”“strict test-then-train evaluation”，把交易收益作为下游验证而不是核心承诺。
